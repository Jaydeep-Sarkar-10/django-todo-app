# 📝 Django Todo App

A modern Todo application built with Django that allows users to manage daily tasks efficiently.

## ✨ Features

- User Authentication
- Login & Signup
- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Responsive UI

## 🛠️ Tech Stack

- Python
- Django
- HTML
- CSS
- SQLite

## 🚀 Run Locally

```bash
git clone https://github.com/Jaydeep-Sarkar-10/django-todo-app.git

cd django-todo-app

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
